====================
Vivado and VCS Setup
====================

If you are on the SLAC SDF network
==================================

Source the SLAC-provided Vivado and VCS environment setup script:

.. code-block:: bash

   $ source /sdf/group/faders/tools/xilinx/2025.2/settings.sh

Note: this path may change with the toolchain version. Refer to the
current SDF administration for the up-to-date path.

If you are NOT on the SLAC SDF network
======================================

You will need to install and license Vivado (2025.2 or newer is recommended)
and, for VCS-based simulation, install Synopsys VCS.

* Xilinx Vivado download: https://www.xilinx.com/support/download.html
* Xilinx Licensing:       https://www.xilinx.com/support/licensing_solution_center.html
* Synopsys VCS:           https://www.synopsys.com/verification/simulation/vcs.html
