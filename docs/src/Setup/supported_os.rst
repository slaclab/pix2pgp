===========================
Supported Operating Systems
===========================

Pix2PGP has been developed and tested on Linux systems, primarily on the
SLAC SDF cluster.

For the VCS-based behavioral simulation flow, make sure your OS is supported
by both Vivado and VCS. Refer to:

  https://docs.amd.com/r/en-US/ug973-vivado-release-notes-install-license/Supported-Operating-Systems

For the GHDL-based flow, any recent Linux distribution capable of running
GHDL will do.
