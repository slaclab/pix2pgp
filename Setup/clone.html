How to Clone the pix2pgp Repository

Pix2PGP relies on git submodules for its external dependencies (SURF and Ruckus). Clone the repository with --recurse-submodules:

$ git clone --recurse-submodules https://github.com/slaclab/pix2pgp.git

If the submodules were not fetched at clone time, they can be initialized afterwards:

$ cd pix2pgp
$ git submodule update --init --recursive
