ASIC Top-Level Wrapper

Every supported ASIC has a wrapper Pix2Pgp<AsicName>Top under gateware/asics/<AsicName>/rtl/. It instantiates, for one lane:

  • the shared Pix2PgpTop core (Column Managers, Column Supervisor, Arbiter)

  • the Pix2Pgp4TxLiteWrapper (PGP4 transmitter)

  • a 66-bit → 32-bit Gearbox toward the serializer

  • the clock-domain synchronizers and capture registers for the configuration inputs

The wrapper exposes only std_logic / std_logic_vector ports, with hardcoded widths, so it can be instantiated from a SystemVerilog / Verilog ASIC top. Asserts inside the wrapper check every port width against the constants of Pix2PgpAsicPkg.vhd at elaboration time. Instantiate the wrapper NUM_OF_SERIALIZERS_C times per ASIC.

Configuration Interface

The cfg* inputs come from the ASIC’s slow-control register file and are treated as asynchronous. The wrapper synchronizes each one to the clock domain where it is used, then captures it into the internal config record while cfgSel is high.

EoF Flag Support (New ASICs)

New ASICs should set EN_EOF_FLAG_C = True in Pix2PgpAsicPkg.vhd (see Header EoF Flag). Their wrapper should then add:

  • a cfgMaskEofPause : in std_logic port

  • a surf.Synchronizer that brings it into the pgpClk domain, in the same way cfgColumnEnable becomes cfgColumnEnablePgp

  • a capture of the synchronized value into config.maskEofPause under cfgSel, in the pgpClk configuration process

maskEofPause

Header EoF flag

'0' (default)

High only on non-Pause readouts in which every enabled column closed with eof

'1'

Pause is ignored: high whenever every enabled column’s Status Word carries the EoF bit, including Pause readouts

On ASICs that predate the feature (SparkPix-S, SparkPix-Sv2, SparkPix-T, Thriglav), the port does not exist and config.maskEofPause is tied to '0'.
