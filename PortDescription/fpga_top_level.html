FPGA Top-Level (Pix2PgpAsicStreamRx)

Pix2PgpAsicStreamRx (firmware/fpga/rtl/Pix2PgpAsicStreamRx.vhd) is the FPGA receiver for one ASIC. It contains:

  • one LaneRxWrapper per lane (LaneRx plus optional LaneMon)

  • the Lane Supervisor and the Lane Merger

  • the Trigger Manager (SRO / ERO / DAQ buffering)

  • the AXI-Lite register manager, behind an AxiLiteAsync and an AxiLiteCrossbar

  • an output AxiStreamFifoV2 + AxiStreamGearbox stage that re-packs tKeep on the consolidated stream

It must be compiled against the same Pix2PgpAsicPkg.vhd as the ASIC, since every header bit position comes from that package. Instantiate one Pix2PgpAsicStreamRx per ASIC.

L = NUM_OF_SERIALIZERS_C below.

Depth of each LaneRx data FIFO, as log2. The first-level input FIFO in front of it uses LANE_FIFO_ADDR_WIDTH_G - 2. Increase for large Pause-fragmented events

AXIL_BASE_ADDR_G

slv(31 downto 0)

(none)

Base address of the receiver’s AXI-Lite region. The crossbar has L + 1 slots of 64 KiB (addrBits = 16): slot 0 holds the receiver’s global registers (Pix2PgpAxiLiteManager), and slot 1 + i holds the LaneMon of lane i. The slot index is decoded from the bits between bit 16 and the lowest set bit of the base (bit 26 if the base is zero). So the base must be aligned so that 2**(lowestSetBit - 16) >= L + 1

General Interface

Description

pgpRxClk

Receiver clock. Every LaneRx (its laneClk is tied to this), the Lane Supervisor, the Lane Merger, the AXI-Lite manager and the output stream run on it. The pgp4Rx* and asicRx* interfaces must be synchronous to it

sl

ASIC Domain Interface

Every port in this group is on the asicClk domain. The Trigger Manager handles the crossing into pgpRxClk.

Dir

Type

Description

asicSro

in

sl

Start-of-Readout, as forwarded to the ASIC. A rising edge increments the FPGA Trigger Counter (if asicSroEn is high, or if the incrSroEnLow register is set). A falling edge pushes {trgCnt, asicSroEn, sysDaq} into the SRO buffer

asicSroEn

in

sl

High if the SRO actually reached the ASIC. When low, the SRO is still buffered, but the Lane Supervisor sends a drop-frame for it instead of waiting for lane data

asicEro

in

sl

End-of-Readout. Only used when EN_ERO_C = True; otherwise it may be left open (default '0'). A falling edge pushes the Trigger Counter of the SRO it closes into the ERO buffer, which the Lane Supervisor uses to close the event. The trigger logic must keep the SRO → ERO → SRO … sequence intact

sysDaq

in

sl

DAQ flag, sampled on the SRO falling edge (LCLS DAQ trigger). If it was low, the consolidated frame for that trigger is dumped and not forwarded downstream. Tie high to always forward
